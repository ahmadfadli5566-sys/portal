Panduan Penyimpanan & Pembagian File

Langkah-langkah untuk menyimpan portal ini dan membagikannya via Google Drive agar dapat diakses publik/siswa.

1 Cara Menyimpan Kode ini ke PC/Laptop

  1. Salin (copy) seluruh kode HTML di halaman ini.
  2. Buka aplikasi **Notepad** (Windows) atau **TextEdit** (Mac).
  3. Tempelkan (paste) kode ke dalam Notepad.
  4. Klik **File > Save As...**
  5. Beri nama file: portal_guru.html
  6. Pada pilihan *Save as type*, pilih **All Files (*.*)** lalu simpan.

2 Mengunggah & Membagikan via Google Drive

  1. Buka Google Drive di browser Anda.
  2. Unggah file portal_guru.html yang sudah dibuat.
  3. Klik kanan pada file di Google Drive > pilih **Bagikan (Share)**.
  4. Ubah akses dari *Dibatasi* menjadi **"Siapa saja yang memiliki link"**.
  5. Untuk membuka langsung sebagai web interaktif, gunakan layanan pihak ketiga seperti **HTML Viewer for Google Drive** atau unduh file untuk dibuka di browser masing-masing.
