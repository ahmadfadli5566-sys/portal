Panduan Simpan & Berbagi lewat Google Drive

  1. Simpan kode ini dalam sebuah file dengan nama index.html atau PortalGuru.html.
  2. Buka Google Drive Anda, lalu unggah file HTML tersebut ke dalam folder pilihan.
  3. Ubah akses berbagi menjadi "Siapa saja yang memiliki link dapat melihat" (Anyone with the link can view).
  4. Untuk menjalankan web langsung dari Google Drive secara interaktif:
    • Gunakan ekstensi Google Drive seperti "HTML Viewer for Drive" atau layanan seperti drv.tw.
    • Atau unduh langsung file HTML dari link drive tersebut dan buka langsung menggunakan browser pilihan (Chrome/Edge/Firefox).
